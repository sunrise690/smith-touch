# Smith Touch

面向手机和平板的 Smith 圆图与射频阻抗匹配工作台。用手指拖动负载、点选电路元件并调整数值，在浏览器中完成理想匹配网络设计。

**打开网页：[https://sunrise690.github.io/smith-touch/](https://sunrise690.github.io/smith-touch/)**

项目采用原生 JavaScript、SVG 和 CSS，计算与文件处理在当前设备完成，无需安装 Windows 软件或连接计算服务器。

## 触控操作

1. 在 Smith 圆图空白处点按或拖动，设置负载位置；点击网络节点查看对应阻抗、驻波比和回波损耗。
2. 点按工作频率、参考阻抗或元件数值，使用应用内的大按钮数字盘输入。也可通过滑条、加减步进按钮调整，不需要唤起系统虚拟键盘。
3. 从元件栏添加串联或并联 R/L/C、传输线、开路支节和短路支节。网络按从负载向输入端的顺序计算；点选元件后可修改、旁路、前后移动或移除。
4. 开启频率扫描，查看圆图轨迹和回波损耗曲线；拖动频率滑条，检查当前工作点。

提供匹配负载、感性负载、L 型匹配和四分之一波长变换示例，以及从当前输入端继续计算 L 型匹配的入口。网页会根据屏幕宽度调整布局，手机竖屏与平板横屏均可使用。

## 保存、导入与导出

工程自动保存在当前浏览器的本地存储中。清除网站数据或更换浏览器后，本地保存不会自动同步，因此需要长期保留时请下载 JSON 工程。

| 操作 | 格式与范围 |
| --- | --- |
| 保存工程、重新导入 | 本应用的 `.json` 工程文件 |
| 导入测量数据 | Touchstone 1.0 `.s1p`、`.s2p`；使用 S11，支持 RI/MA/DB 与 Hz/kHz/MHz/GHz |
| 导入原软件工程 | `.SMC` 文本格式的已实现子集；不支持的元件或覆盖层会提示 |
| 导出圆图 | 独立 SVG 文件 |
| 导出扫描结果 | CSV 文件 |
| 分享当前设计 | “复制工程链接”，由接收者在浏览器中打开 |

Touchstone 负载在频点之间采用 S11 复数线性插值，超出文件频带时取最近端点。SMC 中的多频负载会保留为扫频输入；原程序的宽带结果缓存被重新计算。文件在设备本地读取，不上传到计算服务。

## 加到手机或平板主屏幕

先联网完整打开网页，等待页面资源加载完成。

- iPhone / iPad：在 Safari 中打开，使用分享菜单的“添加到主屏幕”。
- Android：在支持安装的网站浏览器中，使用“安装应用”或“添加到主屏幕”。

首次成功加载并建立离线缓存后，可离线继续使用计算、编辑以及本地文件功能。离线缓存是否保留取决于浏览器和设备的存储管理；新设备仍需先联网打开一次。网页更新后联网重新打开可获取新版本。

## 本地运行与验证

需要 Node.js 20 或以上，建议使用 Node.js 24。项目没有运行时第三方依赖，不需要执行依赖安装。

```sh
git clone https://github.com/sunrise690/smith-touch.git
cd smith-touch
node scripts/serve.js
```

打开终端打印的本地预览地址。ES 模块和离线功能需要通过 HTTP 服务运行，请使用本地服务，不要双击 `index.html` 后以 `file://` 打开。

运行测试：

```sh
node --test
```

本次交付的 40 项计算测试、五种视口的触摸与数字盘检查，以及线上离线缓存检查均已通过，详见 [验证记录](docs/verification.md)。

生成静态发布目录：

```sh
node scripts/build.js
```

构建产物位于 `dist/`。若环境中有 npm，也可使用对应的 `npm run dev`、`npm test` 和 `npm run build`。GitHub Pages 从 `main` 分支根目录自动发布；发布前已运行计算测试与浏览器检查。网页使用相对路径，可部署在仓库子路径下。

## 模型与实现范围

计算采用理想集中元件与无耗传输线，电感单位为 nH、电容为 pF、阻抗为 Ω、频率为 MHz。传输线及支节存储的是参考频率处的电长度，扫频时电长度与频率成正比。触控负载编辑限制在无源区域。

已实现复阻抗与反射系数转换、阻抗及导纳网格、节点匹配轨迹、驻波比与回波损耗、R/L/C 级联、传输线与并联支节、扫频、撤销重做及文件交换。它不包含器件寄生参数、传输线损耗或色散。

原软件的稳定圆、噪声圆、增益圆、MAG/MSG、完整二端口参数绘图和 H/Z/Y/A 转换，以及变压器和组合 RLC 等功能尚未实现。`.s2p` 导入目前提取 S11 作为负载数据，不是完整二端口网络仿真。SMC 兼容性限于已观察格式；导入提示中的遗漏会影响对原设计的完整复现。

## 独立重写与验证依据

本项目根据用户提供的 Smith V2.01 的可观察功能、文本工程格式和公开射频关系独立编写，没有反编译或复用原软件源码。仓库不包含原软件可执行文件、原图标、帮助文档、许可证密钥或原示例文件。

在本机用三份原工程的 12 个元件逐节点交叉核验，阻抗实部及虚部的最大绝对差低于 `1.5 × 10⁻⁴ Ω`；完整结果与解释见 [功能观察与兼容边界](docs/reverse-engineering.md)。单元测试另外检查边界条件、元件单位、无耗传输线、文件解析和独立 ABCD 计算的一致性。

RF 原理可参考 scikit-rf 官方文档：

- [负载阻抗与反射系数关系](https://scikit-rf.readthedocs.io/en/latest/api/generated/skrf.tlineFunctions.zl_2_Gamma0.html)
- [给定电长度的传输线输入阻抗](https://scikit-rf.readthedocs.io/en/latest/api/generated/skrf.tlineFunctions.zl_2_zin.html)
- [网络参数、Touchstone 文件与 ABCD 表示](https://scikit-rf.readthedocs.io/en/latest/tutorials/Networks.html)

这些链接用于说明公开的射频原理，本应用不依赖 scikit-rf Python 包。新增源码按仓库中的 MIT 许可证提供。
